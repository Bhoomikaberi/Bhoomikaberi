## 📌 Featured Projects

### 📉 Telecom Customer Churn Prediction Platform
`Python` `Scikit-learn` `Flask` `Pandas` `NumPy` `Joblib`

End-to-end churn prediction on the IBM Telco dataset: preprocessing, feature engineering, and a comparison of Random Forest, Logistic Regression, and HistGradientBoosting using ROC-AUC and accuracy. Includes a Flask REST API and interactive dashboard for real-time predictions, probability estimates, and retention recommendations.

### 🏃 Human Activity Recognition Platform
`Python` `TensorFlow` `Keras` `FastAPI` `React` `Vite`

A CNN–LSTM model trained on the UCI HAR dataset (10,299 samples, 561 sensor features), reaching **93%+ accuracy**. Served through a FastAPI backend and React + Vite dashboard showing real-time inference, confidence scores, training metrics, and confusion matrix analysis.

### 📄 PerfectCV: AI Resume Evaluator
`Python` `NLP` `TF-IDF` `Scikit-learn` `React.js`

Evaluates resumes with TF-IDF vectorisation and semantic similarity to produce personalised feedback and ATS-style scoring. Helped **100+ users** improve CV quality by roughly **40%**.
